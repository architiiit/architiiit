## **Selected Projects**

### 🔒 AES-256 Multi-Mode Cryptographic Accelerator
- Implemented AES-256 encryption and decryption supporting ECB, CBC, CTR, and GCM modes.
- Developed RTL control logic, datapaths, key expansion, and top-level integration.
- Performed simulation and FPGA validation.

### 🔑 AES Key Wrap with Padding (KWP)
- Designed wrapping and unwrapping hardware compliant with **NIST SP 800-38F**.
- Focused on control logic, secure key handling, and functional validation.

### 🛡️ PUF-Based Secure Key Protection
- Developed a secure key-protection flow on AMD/Xilinx Zynq UltraScale+ MPSoC.
- Integrated PUF registration, AES-GCM-based key wrapping, QSPI Flash storage/retrieval, and authenticated key recovery.

### 🧪 NIST Cryptographic Validation Framework
- Validated AES implementations using KAT, MCT, MMT, GFSbox, KeySbox, Variable Key, and Variable Text test suites.
- Used simulation, waveform analysis, and on-board debugging to investigate functional issues.

### 🔌 UART & AXI-Based FPGA Integration
- Developed UART-based host-to-FPGA communication and validation modules.
- Integrated AXI4-Stream, AXI4-Lite, and DMA-based PS–PL data/control paths.

### 🎧 Acoustic Source Localization
- Implemented Delay-and-Sum beamforming with FFT-based processing and the MUSIC algorithm in MATLAB as part of honors research.
